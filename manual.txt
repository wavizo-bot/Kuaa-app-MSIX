FLUXO DE ATUALIZACAO (ordem certa):
  1. Edita o fonte em C:\APPS\Kuaa\kuaa-app e roda `npm run build` la.
  2. Roda `.\sync-msix.ps1 -App app` em C:\APPS\Kuaa (atualiza espelho + Mapping).
  3. Se mudou a versao da loja: edita Version em AppxManifest.xml + $PackageName
     no build-msix.ps1 + este manual (toda versao sobe os 3 juntos).
  4. Roda `.\build-msix.ps1` aqui (precisa SDK do Windows + .NET 8).
  5. Commit + push; anexa o .msix na submissao do Partner Center (ID acima).

REGRAS:
  - Nunca commitar *.msix, PackageOutput/, bin/, obj/, *.pfx (ver .gitignore).
  - Nunca editar os arquivos-espelho a mao: eles sao sobrescritos pelo sync.
  - __manus__/ nao entra no pacote (debug de desenvolvimento, sem referencia).
